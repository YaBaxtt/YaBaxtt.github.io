# PACH — backend portfolio

Статичный одностраничный сайт для GitHub Pages: HTML, CSS и JavaScript без сборки и фреймворков.

## Перед публикацией

В [`script.js`](script.js) укажи свои три реальные ссылки в объекте `profileLinks`:

- GitHub-профиль;
- Telegram-канал;
- Telegram-личка.

Затем загрузи содержимое этой папки в репозиторий и включи **Settings → Pages → Deploy from a branch → main / root**. Сайт откроется по адресу `https://<username>.github.io/<repository>/`.
